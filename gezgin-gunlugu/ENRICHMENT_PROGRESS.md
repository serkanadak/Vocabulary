# Yerel Arşiv Zenginleştirme Planı

Amaç: yerel arşivi zenginleştirmek — (a) mevcut mid-tier şehirlerin mekan
listelerini genişletmek, (b) turistik potansiyeli orta ama popüler güzergahların
ana ara/geçiş duraklarını eklemek (Sirmione, Graz gibi). Her batch: yeni yerler
+ mekanları, sonra doğrulama + commit + PR + merge + deploy. Batch bitince
sıradakine geç; hepsi bitince zamanlayıcıyı durdur.

İşaretleme: [x] tamamlandı, [ ] bekliyor. (Kaldığın yeri buradan ve veriden anla.)
